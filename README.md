# GitHub Achievements Explorer

This repository is a clean, minimalistic space dedicated to exploring and unlocking GitHub Profile Achievements. 

Instead of spamming existing open-source projects or creating noisy pull requests elsewhere, this repository was created as a sandboxed environment to genuinely understand how GitHub's achievement triggers (like *Quickdraw*, *YOLO*, *Pull Shark*, and *Pair Extraordinaire*) work behind the scenes.

## Earned Badges
- **Quickdraw**: Closing an issue/PR within 5 minutes of opening.
- **YOLO**: Merging a pull request without code review.
- **Pull Shark**: Having multiple pull requests successfully merged.
- **Pair Extraordinaire**: Co-authoring commits in merged pull requests.

*All contributions in this repository are for educational purposes related to GitHub's gamification system.*
