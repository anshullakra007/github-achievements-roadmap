# 🏆 Unlocking GitHub Achievements (The Right Way)

GitHub achievements are a fun way to gamify your profile, but it's important to earn them **organically and safely**. Spamming random open-source repositories with fake pull requests or issues hurts maintainers. 

Here is the exact, respectful roadmap to unlocking the free badges for your profile.

---

## 🤠 YOLO
**Requirement:** Merge a pull request without code review.
**The Safe Way:**
You should only ever do this on your **own** repositories where you are the sole maintainer.
1. Create a personal project or a sandbox repository.
2. Clone it locally, make a branch, and update some documentation.
3. Push the branch and open a Pull Request.
4. Since it's your own repository, immediately click **Merge pull request** without assigning a reviewer.

## 🎖️ Quickdraw
**Requirement:** Close an issue or pull request within 5 minutes of opening it.
**The Safe Way:**
Again, do this in your **own** repository to avoid spamming maintainers.
1. Go to the Issues tab of your repository.
2. Open an issue (e.g., `Meta: Track future enhancements`).
3. If you immediately decide to move that tracking to an external tool like Notion, you can instantly click **Close issue**.

## 🦈 Pull Shark
**Requirement:** Open pull requests that have been merged. (Tier 1 requires 2 merged PRs).
**The Safe Way:**
GitHub's backend looks for genuine contributions, so doing this on your own empty repositories sometimes gets filtered out. The best way is to contribute to a repository explicitly designed for beginners!
1. Fork the amazing [first-contributions/first-contributions](https://github.com/firstcontributions/first-contributions) repository.
2. Clone it locally and create a new branch.
3. Open `Contributors.md` and add your name to the list following their instructions.
4. Commit, push, and open a Pull Request to their upstream repository.
5. Their bot will automatically merge your PR!

## 🤝 Pair Extraordinaire
**Requirement:** Co-author a commit in a merged pull request.
**The Safe Way:**
You can do this while getting your Pull Shark badge! When you are committing your change (for example, adding your name to `first-contributions`), simply add a co-author trailer to your commit message.
1. Write your commit message.
2. Leave exactly one blank line.
3. Add the trailer: `Co-authored-by: Name <email@example.com>`
*(It is common to use the email of a trusted colleague you are pair programming with, or even a friendly bot).*

## 🧠 Galaxy Brain
**Requirement:** Have 2 of your answers accepted in GitHub Discussions.
**The Safe Way:**
You can build a community around your own projects!
1. Enable Discussions in the settings of your most popular repository.
2. If users ask questions in the **Q&A** category, provide excellent, detailed answers.
3. When the user (or you, if you are answering your own architectural question) clicks the `✓` to **Mark as answer**, you make progress toward this badge. You need 2 accepted answers.

---

### ⏳ A Note on Patience
While Quickdraw and YOLO are awarded instantly, GitHub uses background jobs to calculate **Pull Shark**, **Pair Extraordinaire**, and **Galaxy Brain**. 

It is completely normal to wait **24 to 48 hours** for these badges to appear on your profile after you have completed the requirements. Just be patient!
